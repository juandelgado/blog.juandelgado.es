## What is GenUI?

**GenUI is LLMs rendering user interfaces at run time**.

Think complete interface personalization provided by the LLM understanding who you are and what you want to achieve. In real time.

There is a lot to talk about GenUI, but for now I'm not going to put it in writing because in all honesty it'll probably be obsolete by the end of week. It is moving that fast.

So instead I'm going to use this page as a resource centre for the time being. I (vaguely) promise I'll put down my thoughts at one point. In fact, I'm doing a couple of talks about GenUI, I'm hoping they'll be recorded and publicly shared, I'll update this page when available.

Until then, here a few resources I've found useful:

- [VGV's GenUI blog posts](https://verygood.ventures/blog/?tag=GenUI).
- Google Research: [Generative UI: A rich, custom, visual interactive user experience for any prompt](https://research.google/blog/generative-ui-a-rich-custom-visual-interactive-user-experience-for-any-prompt/).
- Google's [Flutter GenUI SDK repository](https://github.com/flutter/genui), which includes sample apps.
- [A2UI.org](https://a2ui.org/), home page of Google's open protocol for agent driven interfaces. Loads of down to earth documentation, including an [intro to the core concepts](https://a2ui.org/concepts/overview/#the-big-picture).
- Thesys' [Generative UI: What It Is and Why It Matters](https://www.thesys.dev/blogs/generative-ui) and [How to Build Generative UI Applications](https://www.thesys.dev/blogs/how-to-build-generative-ui-applications). These are long, but well written deep dives.
- [OpenUI](https://www.openui.com/), alternative to A2UI by Thesys.
